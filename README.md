# Semantic HTML5 Portfolio

A portfolio page built with modern semantic HTML5 and WCAG accessibility guidelines.

## Features
- Semantic tags: header, nav, main, section, article, aside, footer
- ARIA labels and roles for screen readers
- SEO-friendly meta tags (description, Open Graph, canonical)
- Accessible, tab-navigable contact form with labels and a fieldset
- Skip-to-content link

## Run locally
Open `task1-semantic-portfolio.html` in your browser.
